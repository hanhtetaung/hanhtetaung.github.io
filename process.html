Workflow

  • Inspiration

    Research ideas and references. This produces the foundation and overall direction for how the website should look and feel.

  • Wireframe

    Plan the structure and layout of the website. This step produces a simple blueprint and storytelling flow.

  • Design

    Craft the polished visual interface. This produces the colors, typography, optimized images, and overall visual system for the website.

  • Develop

    Build the website from the previous step using HTML, CSS, and JavaScript. This produces the final working code for the website.

  • Deliver

    Push the code to the repository and automate the deployment process. This produces a live website within seconds.
